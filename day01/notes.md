# Day 01：变量、数据类型与 printf

## 今日目标

理解 C 程序最基本的变量、数据类型和输出。

## 核心知识

### 1. 变量

变量用于保存数据。

```c
int age = 21;
```

这里 `age` 是变量名，`21` 是保存的值，`int` 表示整数类型。

### 2. 常见数据类型

| 类型 | 用途 | 示例 |
|---|---|---|
| `int` | 整数 | `21` |
| `float` | 单精度小数 | `3.14f` |
| `double` | 双精度小数 | `3.14159` |
| `char` | 单个字符 | `'A'` |

### 3. printf

`printf()` 用来向终端输出内容。

```c
printf("Hello, C!\\n");
```

常见格式说明符：

- `%d`：int
- `%f`：float / double 输出时常用
- `%c`：char
- `%s`：字符串

### 4. 声明与赋值

```c
int age;
age = 21;
```

也可以直接初始化：

```c
int age = 21;
```

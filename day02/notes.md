# Day 02：scanf、输入与输出

## 今日目标

学会让程序从键盘读取数据，并把读取到的数据输出出来。

## 核心知识

### 1. `scanf()`

`printf()` 是程序把内容输出到屏幕；`scanf()` 是程序从键盘读取内容。

```c
int age;

scanf("%d", &age);
```

可以先把这句理解为：读取一个整数，并把它保存到 `age` 中。

注意变量前面的 `&`。现在先记住写法，后面学习指针时会解释它的原因。

### 2. 不同类型的输入格式

| 类型 | `scanf()` 中使用的格式 | 示例 |
|---|---|---|
| `int` | `%d` | `scanf("%d", &age);` |
| `double` | `%lf` | `scanf("%lf", &height);` |
| `char` | ` %c` | `scanf(" %c", &letter);` |

读取 `char` 时，`%c` 前面有一个空格。它能跳过前一次按 Enter 留下的换行符。

### 3. `scanf()` 和 `printf()` 的区别

```c
double height;

scanf("%lf", &height);   // 输入 double 时使用 %lf
printf("%.1f\n", height); // 输出 double 时使用 %f
```

### 4. 两个整数求和

先读取两个整数，再把它们相加。

```text
输入第一个整数：12
输入第二个整数：8
它们的和：20
```

提示：先定义两个整数变量和一个保存结果的变量；使用 `+` 完成相加。

3. 让用户输入一个字母（`char`），再输出该字母。
4. 让用户输入两个整数，计算并输出它们的和。
5. 选做：让用户依次输入年龄、身高和喜欢的字母，并整齐地输出三项信息。

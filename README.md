# C Learning

这是我的 C 语言系统学习仓库。

## 学习目标

- 从变量、数据类型等基础开始重新学习 C
- 掌握条件分支、循环、函数、数组、字符串、指针、结构体、文件操作
- 通过练习建立扎实的编程基础
- 最终能够独立完成小型 C 项目，并为后续学习数据结构、算法、C++、Unity 和其他技术打基础

## 学习方式

每天按照以下流程学习：

1. 学习当天的核心知识
2. 阅读并运行示例代码
3. 完成练习题
4. 提交自己的代码
5. 复盘错误并修改代码
6. 记录当天的学习进度
